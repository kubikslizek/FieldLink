# FieldLink
A tactical field communication device. Something like a walkie - talkie, but better.

# FEATURES:
- Live GPS tracking
- nRF24 chat communication
- Navigation to the other device
- Waypoint navigation
- Compass mode
- Smooth UI with audio feedback

# PARTS LIST:

CORE ELECTRONICS:
- ESP32 DevKit
- nRF24L01 radio module with antenna
- NEO-6M GPS module
- QMC5883L magnetometer module

UI
- Analog joystick
- Water resistant buttons
- ST7735 1.8" TFT color screen
- Piezo buzzer

POWER
- 18650 4.2 V Li-ion cell
- TP4056 battery charger
- ON/OFF switch
- Female USB type C port extender
- Boost converter + stabiliser

WIRING & ASSEMBLY
- Dupont wires
- Pin headers
- Heat shrink tubing
- Screws
- Custom 3D printed enclosure
